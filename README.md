# Customer Segmentation

An unsupervised machine learning project for grouping customers into meaningful segments based on customer attributes and purchasing behavior.

## Project Objective

Use clustering techniques to discover groups of customers with similar characteristics.

## Workflow

- Data exploration
- Data cleaning
- Feature selection
- Feature scaling
- Cluster analysis
- K-Means experimentation
- Selecting an appropriate number of clusters
- Visualizing customer segments
- Interpreting the resulting groups

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Status

Machine learning portfolio project. Documentation and reproducibility will be improved as the project is refined.
